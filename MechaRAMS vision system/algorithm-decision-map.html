Localization

Fused robot pose

The robot's best current estimate of X, Y, and heading. Every driving controller reads this same estimate.

IF

Wheel and gyro updates arrive continuously, and accepted camera observations arrive when tags are visible.

THEN

Combine them into one pose estimate. Vision corrects the estimate but never commands a wheel.

What it affects

Start validation, path progress, the handoff boundary, and final position error.
